# drawing-c4-diagrams: sample output

Real, unedited runs of the skill, so you can see what you get before installing it. Each folder holds the prompt, the full conversation, the Structurizr DSL the skill wrote, and the diagrams it rendered.

| Sample | Shows |
| --- | --- |
| [web-shop](./web-shop/) | A one-line request, the scoping grill one question at a time, Context and Container views, and the review grill |
| [aws-blogging](./aws-blogging/) | Scope given up front (no questions), three views including a Live deployment on AWS with icons |

These are regenerated by hand, not by CI, so they show the skill as of the commit named in each sample. The AWS icons inside the SVGs belong to AWS; see the [icon licensing notes](../../architecture/README.md#icon-licensing-not-legal-advice-checked-2026-11-14-to-2026-11-16).
